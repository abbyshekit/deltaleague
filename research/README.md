# Research records

Each experiment lives in `research/<github-login>-<experiment>/`. Research PRs change only that directory. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the enforced boundaries, size limits, and required evidence.

Store the hypothesis, research trace, reproduction code, aggregate public results, and submission link. Keep weight artifacts, credentials, signed URLs, raw generation logs, and private test material out of Git. PR evidence is not an official leaderboard result.
